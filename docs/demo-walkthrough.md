# Demo walkthrough (about three minutes)

Uses the scripted demo so it works without a model key; the same steps work in live mode (Gemini or Ollama).

1. **Onboarding.** Open http://localhost:8080, choose "Fill in the demo founder" (CS student, EGP 10,000, 15 h/week,
   Egypt, idea: compete with ChatGPT). Continue to the last step, pick *Scripted demo*, start the discussion.
2. **Mate challenges the idea.** Use the demo-script line. Mate explains why a general ChatGPT competitor does not fit
   the budget and asks one question. The right rail tracks readiness and assumptions (all ASSUMPTION).
3. **Narrowing.** Send the next two lines. Mate offers three directions; *Compare directions* scores them with a
   heuristic index. The palette shifts to the learning archetype as the idea becomes about studying.
4. **Proposal #1 rejected.** *Draft a proposal* → review → *Continue challenging the idea* with the reason "students
   rarely pay". The debate continues with full context.
5. **Proposal #2 approved.** Send the tutoring-centres line, draft again, *Approve this business direction*. The
   workspace opens in the same tab; the palette switches to business-operations blue because the plan changed.
6. **Mind map.** Hover *Revenue model* for the preview; open *Founder discussion* on the left; click the node for the
   detail panel on the right (Overview, Economics, Evidence, Tasks, History).
7. **Negotiated edit.** Pencil on *Revenue model*: ask for a one-time price. Mate disagrees and explains; reply with
   the per-term line; approve the revision. The plan moves to v2 and the node shows "edited 1×".
8. **Phases.** Run Phase 1 (research runs; offline it records UNKNOWN honestly) and evaluate the gate. Phase 2:
   record the demo result (labelled MOCKED) and evaluate. Phase 3 builds and tests the MVP (open it under Artifacts).
   Phase 4 waits for your approval. Phase 5: approve, simulate a purchase, deliver, replay the delivery event (no
   second entitlement), refund (access revoked). Phase 6: triage the demo ticket, run, evaluate.
9. **Decision log.** Every agent action, approval, gate and transition with model, cost and approver.
10. **The STOP path.** From the home page start *Scripted demo: an idea that should stop*, send the two lines, draft
    and approve the proposal Mate advised against, run Phase 1 and evaluate: the gate says STOP.
